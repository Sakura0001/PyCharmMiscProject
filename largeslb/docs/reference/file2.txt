## 1. 特性概述

### 1.1 特性简介

MySQL 8.0.41 对 EXPLAIN ANALYZE 命令的输出格式进行了改进，提供了更详细的执行计划分析信息，包括更精确的时间统计、改进的迭代器树可视化格式，以及新增的资源消耗指标。该改进帮助用户更好地理解查询执行过程，优化查询性能。

### 1.2 相关文档

- 官方文档链接：https://dev.mysql.com/doc/refman/8.0/en/explain.html
- Release Notes：https://dev.mysql.com/doc/relnotes/mysql/8.0/en/news-8-0-41.html
- Worklog：WL#xxxxx（待确认）
- 其他参考：MySQL 源码 sql/explain_analyze.cc

### 1.3 特性范围

**包含：**
- EXPLAIN ANALYZE 输出格式改进
- 新增执行时间统计字段
- 改进的迭代器树可视化
- JSON 格式输出增强

**不包含：**
- EXPLAIN FORMAT=TRADITIONAL 的改动（不在本次测试范围）
- EXPLAIN FORMAT=TREE 的改动（仅关注 ANALYZE）

### 7.2 数据生成脚本

```sql
-- 创建测试表
CREATE TABLE t_100k (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100),
    value INT,
    created_at DATETIME,
    INDEX idx_name (name),
    INDEX idx_value (value)
);

-- 使用存储过程插入数据
DELIMITER //
CREATE PROCEDURE populate_t_100k()
BEGIN
    DECLARE i INT DEFAULT 0;
    WHILE i < 100000 DO
        INSERT INTO t_100k (name, value, created_at)
        VALUES (CONCAT('name_', i), i % 1000, NOW() - INTERVAL FLOOR(RAND()*365) DAY);
        SET i = i + 1;
        IF i % 10000 = 0 THEN
            COMMIT;
        END IF;
    END WHILE;
END //
DELIMITER ;

CALL populate_t_100k();
```
