# MySQL 8.0.22 Official Sources

The MySQL factor library uses official Oracle MySQL documentation as the
authoritative source.

## Primary Sources

- MySQL 8.0 Reference Manual, SQL Statements:
  https://dev.mysql.com/doc/refman/8.0/en/sql-statements.html
- MySQL 8.0.22 Release Notes:
  https://dev.mysql.com/doc/relnotes/mysql/8.0/en/news-8-0-22.html
- MySQL 8.0 Release Notes index:
  https://dev.mysql.com/doc/relnotes/mysql/8.0/en/

## Version Rule

When a current manual page documents syntax whose availability is uncertain for
8.0.22, the statement reference must either:

1. cite release notes proving the feature existed in or before 8.0.22, or
2. mark the factor as `excluded_after_8_0_22` until proven.
