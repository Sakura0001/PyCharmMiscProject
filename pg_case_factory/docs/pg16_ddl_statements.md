# PostgreSQL 16 DDL 相关语句清单

来源：PostgreSQL 16 官方 SQL Commands：https://www.postgresql.org/docs/16/sql-commands.html
辅助口径：PostgreSQL 16 Event Trigger Firing Matrix：https://www.postgresql.org/docs/16/event-trigger-matrix.html

纳入口径：SQL Commands 中所有 `CREATE` / `ALTER` / `DROP` 对象定义命令，以及官方事件触发器矩阵支持的非 CREATE/ALTER/DROP DDL command tag；另外补入常见 DDL-adjacent 维护命令 `CLUSTER`、`REASSIGN OWNED`、`REINDEX`、`TRUNCATE`。

排除口径：`GRANT` / `REVOKE` 属于权限控制（DCL），事务、游标、DML、运行时参数、通知、COPY、VACUUM、ANALYZE 等不在本次 DDL skill 生成范围内。

共 136 个语句类型。
